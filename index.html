Piano Ripple

ピアノ音源から音符を推定し、88鍵を紫(A0)から赤(C8)までの虹色に割り当てて、水面に色のついた光が落ちて広がるような波紋の映像(1920×1080 / 30fps)を作ります。

A0(最低音)88鍵 固定パレットC8(最高音)

特長

音高 → 色(全編固定)88鍵を、紫・青・水色・緑・黄・橙・赤へ滑らかに割り当て。橙〜赤に約25鍵を確保。
面のある波紋半透明の色の面が広がり、外縁に厚い明るい波頭。内側に減衰する波列と、発音の瞬間の中心フラッシュ。
水面の表現屈折、色収差、空の反射、鏡面ハイライト、明暗。重なっても白飛びしないソフトクリップ。
決定的な書き出し時刻だけで画面が決まるので、同じ音源から同じ映像。FFmpeg で音声と合成。

セットアップ

必要なもの: Python 3.10+、FFmpeg、Chromium(Playwright)。

pip install numpy scipy pillow playwright
playwright install chromium   # ブラウザがある環境では不要

実行

# 10秒プレビューまで(見た目と同期の確認)
./run_all.sh path/to/piano.mp3 --preview

# 続けて全曲 MP4 を書き出し・検証
./run_all.sh path/to/piano.mp3

個別に実行する場合:

python3 analysis/analyze.py song.mp3 -o out/song.notes.json --debug out/debug
python3 tools/render.py --notes out/song.notes.json --audio song.mp3 --out out/song.mp4 --start 0 --duration 10
python3 tools/verify.py out/song.mp4 --notes out/song.notes.json --audio song.mp3 --start 0

長い曲は、20秒ごとに分けて書き出し、中断しても続きから再開できる tools/render_full.py を使います。 上部の鍵盤表示が不要なときは --no-keyboard を付けます。

構成

パス役割
analysis/analyze.py音源 → 音符イベント JSON、デバッグ出力(ピアノロール PNG・CSV)
analysis/evaluate.py正解データとの照合(適合率・再現率・発音時刻誤差)
web/palette.js88鍵の固定カラーパレット(色の唯一の出典)
web/ripple.js描画エンジン(WebGL2)。renderFrame(t) は時刻だけで決まる
web/index.htmlブラウザでのプレビュー再生(音声の再生位置を時計にする)
tools/render.py / render_full.py固定30fpsでフレームを書き出し、FFmpeg で音声と合成
tools/verify.pyMP4 の長さ・音声同期・映像同期の検証

音符データ(notes.json)

notes[] の各要素: midi, key(0–87), freq, onset, offset, duration, velocity(1–127), peak_db, decay_tau, confidence, flags。 flags には harmonic_of:<midi>(倍音の疑い)、low_confidence、very_short が入ります。 描画側はこの JSON だけに依存するので、別の採譜ツールの出力を同じ形式にすれば差し替えられます。

検証

tools/verify.py が、書き出した MP4 について次を確認します。

  • 解像度・fps・コーデック、映像と音声の長さの差(1フレーム以内)
  • 音声の同期: MP4 から音声を復号し、元音源と相互相関でずれを測定
  • 映像の同期: 発音の瞬間に立ち上がる中心フラッシュの輝度と、notes.json の発音時刻を相互相関

既知の制限

  • 音符検出は NumPy/SciPy の自前実装です。合成テスト曲(密集和音・超高速グリッサンド・残響付き)で F1 約0.48、発音時刻の誤差は中央値で約6msでした。疎な区間は良好ですが、オクターブ重複・密集和音・低音域の高速パッセージは苦手です。
  • 低音域(約E1以下)は、隣り合う鍵を周波数で分離できず、倍音から推定しています。
  • 描画は CPU(SwiftShader)で約1.2秒/フレームです。GPU のある環境では大幅に速くなります。
  • 実音源の検出精度は、正解データがないため未測定です。
